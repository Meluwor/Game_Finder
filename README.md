project name: Game Finder

This project shall ensure a user to find a specific game or maybe a bunch of them with the help of a LLM.
It also shall allow the LLM to make suggestions based on the users favourites or during conservation.

To do so you will need your own API keys (atm: OpenAI,RAWG) which you have to include into the .env file.
like:
OPENAI_GTP_KEY="key",
RAWG_API_KEY="key",
FLASH_KEY="whatever you want here"
